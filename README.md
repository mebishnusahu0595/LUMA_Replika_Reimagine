# Replika Reimagine

A modern AI-powered chatbot designed for healthcare and medical support, built with a 3D avatar frontend and a Node.js backend.  ( Because Replika Doesn't Have Healthcare 3D ChatBot )
This project is split into three main parts:

- **Frontend_!:** Replika website Reimagine
- **Frontend_2:** Interactive 3D chatbot UI (React, Three.js)
- **Backend:** API server for chat responses (Node.js, Express)

---

# 🧠 FAMS Bot — AI Mental Health Chatbot

A powerful AI chatbot designed to support mental wellness, built using modern tech like React, Express.js, Node.js, and more.

## 🚀 Getting Started

Follow these steps to run the full stack app on your local machine:

---

### ✅ Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name 
```

#### 🚀 Step 2: In main directory run :-

```bash
yarn
yarn dev
```
#### 🚀 Step 3: Open a new terminal and run :-

```bash
cd Fams_new/fams_bot_frontend
yarn
yarn dev
```
#### 🚀 Step 3: Again Open a new terminal and run :-

```bash
cd Fams_new/fams_bot_backend
yarn
yarn dev
```
